# Solitaire

Pasiența clasică Klondike, pe telefon: fără reclame, fără cont, merge și fără internet.

- Joacă: https://games.hailatat.icu/solitaire
- Se instalează ca aplicație separată (Chrome pe Android: butonul „📲 Instalează pe telefon” sau meniul ⋮ → Instalează aplicația).
- Când apare o versiune nouă, sus apare butonul „🔄 Versiune nouă – Reîncarcă”. Jocul în curs rămâne salvat.

Next.js 16, deployed on Vercel under `basePath: "/solitaire"` behind the haiLaTăticu hub. See `CLAUDE.md` for details.
